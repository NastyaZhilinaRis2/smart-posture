## Тема проекта
Умное напоминание об осанке.

## Задачи
- Разработка модуля на Raspberry Pi: чтение расстояния с ультразвукового датчика HC-SR04 через GPIO и отправка данных на сервер.
- Разработка Linux-сервера: приём данных, логика определения неправильной осанки, хранение статистики (SQLite), отправка push-уведомлений.
- Создание Android-приложения (Java, Android Studio): отображение текущего статуса и расстояния, статистика за день, настройка порогов срабатывания, приём push.
- Настройка взаимодействия компонентов: HTTP-обмен между Raspberry Pi, сервером и Android-приложением.

## Ожидаемый результат к декабрю 2026 года
Работающий прототип системы контроля осанки: Raspberry Pi с ультразвуковым датчиком, сервер на FastAPI, Android-приложение, документация (README, описание API).
