# Умное напоминание об осанке — серверная часть

## Участники

## Тема проекта
Серверная часть системы контроля осанки.

## Задачи
- Разработка REST API на FastAPI: приём данных от датчика, логика определения неправильной осанки (калибровка, пороги, учёт времени), хранение статистики в PostgreSQL, журнал тревог и заглушка push-уведомлений;
- Покрытие сервера тестами (pytest);
- Настройка CI через GitHub Actions: автоматический запуск тестов при каждом коммите;
- Настройка CD через Railway: автоматический деплой при каждом пуше в main.

## Ожидаемый результат к декабрю 2026 года
Работающий сервер на FastAPI с REST API, покрытый тестами, с настроенным CI/CD через GitHub Actions и Railway, документация (README, описание API).
